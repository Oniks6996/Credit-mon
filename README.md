# Credit-mon
Кредитный монитор, в рамках ТЗ

**как запустить**

Перейти на сервис можно по ссылке: https://credit-monitor.netlify.app/
Далее в выделенное окно необходимо загрузить файл с отчетом из сервиса Кредистория (получить можно по ссылке: https://credistory.ru/cabinet/report/summary), после чего дождавшись распознования данных из PDF возможно будет ознакомиться с клбючевыми полями.

**что работает**

На данный момент загрузка файла, распознавание текста и данных, подсчет данных реализован в соответствии с ТЗ. На данный момент сервис разделен на 5 блоков?
1) Загрузка нового отчета для анализа. В данную зону можно загрузить отчет (повторно или по следующему клиенту для отображения нового отчета);
2) Отчет общих значений, которые показывают сумму по всем имеющимся кредитам, а также по платежам и их распределению, суммы будущих платежей
3) Сравнительный анализ решений - инструмент для рассчета сравнения вариантов погашения, относительно прямого погашения банку или БФЛ и РДГ. Для рассчета необходимо ввести обобщенные условия по БФЛ и РДГ, система рассчитает разницу.
4) Блок детализации кредитов - детализированное описание имеющихся кредитов и их статусы
5) Блок Complience - Это блок с выделением ключевых юридических ограничений и рисков, которые не предусмотрены для озвучивания клиенту, а нужны для передачи в работу юристу.

**какие допущения сделал**

При отсутствии данных по срокам кредитов - рассчетный период 24 месяца
Рассчет месяцев до полного погашения по аннуитету выполнен по формуле: n = -ln(1 - r*P/A) / ln(1+r), где
n - число месяцев;
r - годовой процент по кредиту в месяц;
P, A - Суммы по кредиту
